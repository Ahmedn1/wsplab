# MGSM screen

Screens Qwen3-0.6B on MGSM-Rev2 in English, Bengali and Swahili, with prompting and decoding controls and a
translation probe. Local inference only.

- `python code/mgsm_screen.py <folder> --prepare-only`, then without `--prepare-only`
- `python code/mgsm_controls.py --fixture <folder> --out <dir>`; `python code/mgsm_controls_report.py <dir>`

Reports: [natural-mgsm-screen-results.md](natural-mgsm-screen-results.md),
[natural-mgsm-controls-review.md](natural-mgsm-controls-review.md).
